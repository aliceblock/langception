Welcome to Langception

Langception reads text on your screen and shows its Thai translation. It works immediately with no setup — the default engine is free and keyless. This wizard just checks the two things worth knowing about:

1 · OCR language packs

Windows OCR silently finds nothing for a language whose pack is not installed. You only need the pack for the language you will read (English is usually preinstalled); missing packs for other languages never block anything.

    2 · Translation engine

    Google Translate (unofficial) ☁ cloud active by default

    Free, no key, no setup (ADR-0002). It is a cloud engine: whenever translation runs, screen text is sent to Google's endpoint — a ☁ badge shows this in the tray tooltip and the Results Window. It can rate-limit or break; every failure surfaces visibly.

    Recommended upgrade: Azure AI Translator ☁ cloud

    A keyed, reliable engine on a permanent free tier (F0, 2M chars/month). Click the link to create a Translator resource in the Azure portal (pricing tier "Free F0", region "Global"), then paste its key here — or skip: Google works with zero setup.

    General

    Language, cadence, stability and Genderless Mode apply when translation (re)starts — a running loop restarts automatically. Start-with-Windows applies immediately. Per-app Profiles can override Genderless Mode (Settings → Profiles).

    Engines

    Translate Engine

    The default engine translates every Text Block; per-app Profiles can override it (Settings → Profiles). Google, Azure, DeepL and the OpenAI-compatible endpoint are cloud engines: whenever translation runs, screen text leaves the machine — the ☁ badge shows this in the tray tooltip and the Results Window. LM Studio runs on this machine (offline; text never leaves it), and even it keeps the badge honest: point its URL at another computer and the ☁ badge returns. Quota, key, network and parsing failures surface in the Results Window and as tray notifications.

    Vision reading sends every captured frame to the engine as an image and asks it to read AND translate — noticeably slower per pass than Windows OCR, and on a cloud engine (Gemini, OpenAI-compatible) billed per image. Use it for stylized game fonts that defeat the OCR. The engine must be an LLM with vision (Gemini, OpenAI-compatible, or LM Studio's local vision models); change detection still gates the calls, so an unchanged screen costs nothing. Choose a vision-capable model in the engine's card below (e.g. gemini-2.0-flash).

    Google Translate (unofficial) ☁ cloud

    The keyless default (ADR-0002). Free, but unofficial — it can rate-limit or break, and every failure surfaces visibly. No key, no setup.

    Azure AI Translator ☁ cloud

    The reliable keyed option. The F0 tier is permanently free (2M chars/month): create a Translator resource with the link (pricing tier "Free F0", region "Global"), then paste its key. The region must match the resource; empty means global.

    DeepL ☁ cloud

    The DeepL API free plan (500k chars/month, Thai supported). Sign up with the link and paste the key — free keys end with ":fx", which picks the right API host.

    OpenAI-compatible ☁ cloud (unless your URL is local)

    One adapter for OpenAI, OpenRouter, or any OpenAI-compatible API: set the base URL (must include /v1), paste its key, and type the model name (e.g. gpt-4o-mini). Cloud URLs show the ☁ badge while running; a loopback URL counts as local and does not.

    LM Studio Local · offline

    Local translation through LM Studio's server: start it (LM Studio → Developer → Start server, default port 1234), load a model, then check the server here — the model dropdown fills from what it serves. No key, no cloud: screen text stays on this machine.

    Gemini ☁ cloud

    Google's LLM API: create a free API key at AI Studio with the link, paste it, and type a model id (e.g. gemini-2.0-flash). Like every LLM engine, Glossary terms appearing in a block are injected into the prompt, and Genderless Mode is requested there too.

    OCR Engine — Windows OCR language packs

    The OCR engine reads the screen locally. It needs a Windows language pack for the Source Language you read; a missing pack silently produces nothing, so it is checked here instead.
