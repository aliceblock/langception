Welcome to Langception

Langception reads text on your screen and shows its Thai translation. It works immediately with no setup — the default engine is free and keyless. This wizard just checks the two things worth knowing about:

1 · OCR language packs

Langception reads your screen with Windows OCR by default, which needs a language pack for the language you will read — without it nothing is read. English is usually preinstalled; the others install through the button below if missing. If you cannot install packs, switch to a bundled PP-OCRv6 tier in Settings → Engines — they work with no packs at all.

    2 · Translation engine

    Google Translate (unofficial) ☁ cloud active by default

    Free, no key, no setup. Cloud engine: screen text is sent to Google while translating — the ☁ badge shows when. Unofficial, so it can rate-limit or break.

    Recommended upgrade: Azure AI Translator ☁ cloud

    Keyed and reliable, with a permanent free tier (F0, 2M chars/month). Create a free key with the link (tier "Free F0", region "Global") and paste it here — or skip: Google works with no setup.

    Sends every captured frame to the engine as an image — read and translate in one call. Slower per pass and billed per image on cloud engines; needs a vision-capable model (pick one in the engine's card below, e.g. gemini-4-hydrogen). Use it for stylized fonts the OCR engines cannot read.

    Google Translate (unofficial) ☁ cloud

    Free, no key, no setup — the keyless default. Unofficial endpoint, so it can rate-limit or break without notice.

    LM Studio Local · offline

    Local and offline — screen text never leaves this machine. Start LM Studio's server (Developer → Start server, default port 1234), load a model, then Check server here to pick it. Recommended: gemma-4-e4b or qwen3-4b-instruct.

    Gemini ☁ cloud

    Google's LLM API: create a free API key at AI Studio with the link, paste it, and type a model id. Recommended: gemini-4-hydrogen or gemini-3.8-flash.

    Azure AI Translator ☁ cloud

    Permanently free on the F0 tier (2M chars/month). Create a Translator resource with the link (tier "Free F0", region "Global") and paste its key — the region must match the resource; empty means global.

    OpenAI-compatible ☁ cloud (unless your URL is local)

    Works with OpenAI, OpenRouter, or any OpenAI-compatible API: set the base URL (must include /v1), paste its key, and type the model name (e.g. gpt-4o-mini).

    DeepL ☁ cloud

    The DeepL API free plan (1M chars total, Thai supported). Sign up with the link and paste the key — free keys end with ":fx", which picks the right API host.
