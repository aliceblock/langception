Welcome to Langception

Langception reads text on your screen and shows its Thai translation. It works immediately with no setup — the default engine is free and keyless. This wizard just checks the two things worth knowing about:

1 · OCR language packs

Windows OCR silently finds nothing for a language whose pack is not installed. You only need the pack for the language you will read (English is usually preinstalled); missing packs for other languages never block anything.

    2 · Translation engine

    Google Translate (unofficial) ☁ cloud active by default

    Free, no key, no setup (ADR-0002). It is a cloud engine: whenever translation runs, screen text is sent to Google's endpoint — a ☁ badge shows this in the tray tooltip and the Results Window.

    More engines (Azure, DeepL, Gemini, local models) arrive in later versions — see Settings → Engines. You can skip the rest for now: translation works with zero configuration.

    General

    Language, cadence and stability apply when translation (re)starts — a running loop restarts automatically. Start-with-Windows applies immediately.

    Engines

    Translate Engine

    Google Translate (unofficial) ☁ cloud

    The keyless default (ADR-0002). Free, but unofficial — it can rate-limit or break, and every failure surfaces visibly. More engines (Azure F0, DeepL, Gemini, OpenAI-compatible, local models) arrive in later versions; a cloud engine always shows the ☁ privacy badge in the tray tooltip and the Results Window.

    OCR Engine — Windows OCR language packs

    The OCR engine reads the screen locally. It needs a Windows language pack for the Source Language you read; a missing pack silently produces nothing, so it is checked here instead.
